# Мафиозник

Приложение ведущего для офлайн-игр в спортивную мафию. Техническое задание: [docs/TZ.md](docs/TZ.md).

## Команды

```
npm install      # установить зависимости
npm run dev      # запустить в режиме разработки
npm test         # прогнать тесты
npm run build    # проверить типы и собрать
```

## Устройство

- `src/engine` — логика игры без интерфейса.
  - `types.ts` — роли, фазы, состояние игры, события ведущего.
  - `regulation.ts` — регламент по умолчанию (ФИИМ). Все правила и баллы настраиваются здесь.
  - `game.ts` — создание игры и применение событий.
  - `scoring.ts` — подсчёт баллов.
  - `labels.ts` — русские названия фаз и подсказки ведущему.
  - `game.test.ts` — тесты сценариев игры.
- `src/session` — партия как журнал действий, отмена и автосохранение.
- `src/storage` — хранилище на устройстве (IndexedDB, запасной вариант localStorage).
- `src/ui` — интерфейс ведущего: рассадка, игровой экран, итоги.
- `src/App.tsx` — переходы между экранами.

## Как устроен движок

Каждое действие ведущего — это событие: «следующий», «выставление», «голосование», «выстрел», «фол» и так далее. Состояние игры полностью вычисляется из журнала событий функцией `replay`. Поэтому отмена действия — это пересчёт журнала без последнего события. Исправление прошлого действия — замена события в журнале и пересчёт. Функция `tryReplay` покажет, если исправление ломает дальнейший ход игры.
